# Reading List

Add new items as dated markdown bullets: `- YYYY-MM-DD [Title](https://example.com/)`.
Use checklist syntax to track progress: `- [ ] YYYY-MM-DD [Title](https://example.com/)` for to-read, `- [x] YYYY-MM-DD [Title](https://example.com/)` for done.
Bare bullets without a checkbox are treated as to-read.
The page sorts them newest first. Checking/unchecking in the UI saves locally (localStorage) and overrides the file's `[x]` default.
